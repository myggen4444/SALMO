# SALMO
Tilhørende kode til prosjekt i emne TTT4270

server_v3 er mappen med kode som lastes opp til en esp32 for å håndtere innhenting av data fra diverse sensorer. Den hånterer også en enkel web siden som gir bruker tilgang til all dataen i live tid.

salinitet er mappen med kode som drifter en esp32 som håndterer en enke og selvprodusert salinitetssensor.

vannstrom mappen inneholder arduino kode som styrer magnetene som er blitt brukt i produksjon av vannstrømms-sensoren.

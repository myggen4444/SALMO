# SALMO
Tilhørende kode til prosjekt i emne TTT4270

server_v3 er mappen med kode som lastes opp til mikrkontroller 1, for å håndtere innhenting av data fra diverse sensorer. Den hånterer også en enkel web side som gir bruker tilgang til all dataen i live tid.

salinitet er mappen med kode som drifter mikrokontroller 2 som håndterer en enkel og selvprodusert salinitetssensor.

vannstrom mappen inneholder arduino kode som styrer magnetene som er blitt brukt i produksjon av vannstrømms-sensoren.
